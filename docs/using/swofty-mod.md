# In-game mod settings

SwoftyMod is the built-in mod that adds **MOD SETTINGS** to the home menu, directly under **Career**. It is always enabled in modded profiles.

The home screen also has an **F9** keyboard prompt (**R3** on a controller) and a panel showing that you launched with F1 Mod Manager.

## Current status

The MOD SETTINGS entry currently opens the game's Settings page. The dedicated page for mod options is still in development.

If the game build is not recognised, the menu entry may be unavailable.

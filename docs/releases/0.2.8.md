# 0.2.8

Swofty Launcher for F1 25 0.2.8 updates the offline play extension to 0.3.3. On EA-app builds of the game, the activation gate inside the game's own `Core/Activation64.dll` ended the session seconds in with exit code 100010. The gate is now answered the same way as every other local check: one shape-verified byte, failing closed when a build differs.

Download it from [Releases](https://github.com/Swofty-Developments/SwoftyLauncher/releases). The launcher offers each new release itself.

## Offline play

- EA-app builds: the game's activation gate passes for the session instead of ending it with exit code 100010. The answer is a single verified byte in the game's own activation module; builds whose code differs are left untouched.
- Session logs record every module the game loads, so a run report shows exactly what the game pulled in, anti-cheat components included.

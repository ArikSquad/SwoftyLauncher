# 0.2.6

Swofty Launcher for F1 25 0.2.6 simplifies the offline play dialog. It now states what matters for the decision — modded sessions run offline, multiplayer is unavailable, EA's terms do not cover it, and the game folder is back to vanilla when the game exits — and leaves the technical mechanics to the docs.

Download it from [Releases](https://github.com/Swofty-Developments/SwoftyLauncher/releases). The launcher offers each new release itself.

## Offline play

- The dialog no longer explains how the session works internally. The command line terms match, and the details are in the docs for anyone who wants them.
- The terms are bound to the exact wording, so the shorter dialog is accepted once.

# 0.2.5

Swofty Launcher for F1 25 0.2.5 updates the offline play extension to 0.3.1. A live self-test of the runtime signature method — added in 0.2.4 — caught an injection bug before it reached players: the hook could not be loaded into the game before it started. It now arms the moment the game loads its imports, still far ahead of the launch check.

Download it from [Releases](https://github.com/Swofty-Developments/SwoftyLauncher/releases). The launcher offers each new release itself.

## Offline play

- On protected builds the session launcher now loads the hook into the game at the first sight of its imports instead of while the process is still suspended, where nothing is loaded yet. The launch check runs 0.4 to 2 seconds in; the method arms well before that.
- The runtime signature method is verified end to end by a self-test that performs the game's own call: unarmed, the signature query on the launcher path fails; armed, the same query returns a genuine EA signature; unrelated paths are never rewritten.

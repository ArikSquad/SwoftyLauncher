# 1.5.4

Swofty Launcher for F1 25 1.5.4 asks to restart as administrator when F1 25 is in a folder only administrators can change, such as the EA app's Program Files folder. Launches no longer stop after a repair in the EA app or a Steam verify, and addons can run their own post-process shaders on the race picture.

## Launching

- When Swofty Launcher can't change the game folder, Play stops before anything is built and **F1 25 needs administrator rights** names the folder. **Restart as administrator** starts Swofty Launcher again with administrator rights; moving F1 25 outside Program Files in the EA app also works. On the EA app copy, close the EA app before restarting. Earlier launchers stopped with "the wrapper exited (exit code: 1)" and "Access is denied". See [A game folder only administrators can change](/using/game-copies#a-game-folder-only-administrators-can-change).
- `swofty apply` and `swofty run --apply` stop with the same message.
- After a repair in the EA app or a Steam verify puts the game's anti-cheat launcher back, offline play counts it as restored. The setup and every launch stopped with "offline-play restore could not finish cleanly" before.

## Addons

- Addons that list `postfx` run their own post-process passes on the race picture before the HUD draws, and the Addons page tags them **Changes the picture**. Swofty Launcher ships the shader compiler they need.

## For addon makers

- Post-process passes: HLSL in the addon, compiled when the profile builds, with the scene colour, the depth buffer, the resolution, the time and the addon's option values. `swofty postfx compile <addon folder>` checks a pass. See [Post-process passes](/reference/addons/postfx).
- The `set-material` ERP operation changes material constants, such as car paint and tyre stripe colours, and takes its values from options. See [Materials](/reference/ops/erp#materials).
- `SWOFTY_POSTFX=0` turns every pass off for a session, and `SWOFTY_POSTFX_CAPTURE=<folder>` writes the picture before and after the passes. See [Logging](/reference/std/logging).

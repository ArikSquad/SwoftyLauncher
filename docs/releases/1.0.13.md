# 1.0.13

Swofty Launcher for F1 25 1.0.13 builds track packages whose override values are written as numbers, such as Pajko's Hockenheimring. Those packages stopped every launch of a profile that had them on with `invalid track package: invalid type: floating point, expected a string`. See [Track packages](/reference/mods/tracks).

Download it from [Releases](https://github.com/Swofty-Developments/SwoftyLauncher/releases) or with the [installer](/guide/installation). The launcher offers each new release itself.

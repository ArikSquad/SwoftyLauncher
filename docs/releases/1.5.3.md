# 1.5.3

Swofty Launcher for F1 25 1.5.3 adds four categories to the Addon Browser and lists every addon under the category tiles. Installing several addons at once no longer fails when they need the same addon, and what addons draw over the game shows at the right brightness on HDR displays.

## Addon Browser

- New categories: **Career**, **AI**, **Performance** and **Utility**, each with a tile. Career Mode Editor, Driver Manager and R&D: Tyres & Thermal Management are under Career, and F1 25 RE-Optimization is under Performance.
- Every addon is listed under the tiles, with the count and the sort order, in place of the **All addons** tile. See [Addon Browser](/using/addon-browser).
- Installing several addons at once that need the same addon, such as the Classic Seasons years, no longer fails with "Could not find EOCD" or "The system cannot find the file specified". The shared addon downloads once and installs once.

## Addons that draw over the game

- On an HDR display, what addons draw over the game shows at the brightness of the game's own HUD instead of full brightness.
- SwoftyMod draws addons' shapes and text in a layer of its own and puts it over the game's picture in one pass, without waiting for the graphics card.
- Shader packs and addons that draw over the game share one set of hooks into the game's renderer.

## For addon makers

- The race HUD library shows a message in the game's own race notification, with a flag icon, through `swofty::hud::toast`. `swofty::hud::set` writes a value the race HUD shows. See [Race HUD](/reference/std/hud).
- The categories `career`, `ai`, `performance` and `utility` need launcher 1.5.3 or later; earlier launchers refuse a manifest that uses one. From 1.5.3, a category the launcher doesn't know reads as no category. See [category](/reference/addons/manifest#category).
- `SWOFTY_OVERLAY_NITS` sets the overlay's brightness on HDR output, and `SWOFTY_OVERLAY_KILL` turns parts of the overlay off. See [Logging](/reference/std/logging).

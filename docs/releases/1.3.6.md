# 1.3.6

Swofty Launcher for F1 25 1.3.6 gives addons their own row in the Grand Prix and Time Trial era picker, sorts the Addons page into four categories and fixes builds that combine an imported car pack with R&D: Tyres & Thermal Management.

## Era picker

- SwoftyMod splits the era picker of **Grand Prix** and **Time Trial** into two rows. **Built In** holds the game's own eras, such as F1 2026 and F2 2026, and **Addons** holds the eras that addons add. Each row scrolls sideways on its own; **Up** and **Down** move between them. See [SwoftyMod](/using/swofty-mod#era-picker).
- An addon adds a box to the Addons row with `swofty::era::add_box` in `swofty/era.hpp`, and adds its entrant list to the new `swofty_f1` mode with `list-append`. Pressing the box loads only that entrant list. See [Era picker boxes](/reference/std/era-picker) and [Rows SwoftyMod adds](/reference/ops/database#rows-swoftymod-adds).

## Addons page

- Addons are sorted into **Seasons**, **Tracks**, **Cars**, **Helmets** and **Uncategorised**. Addons made for earlier launchers still install: `liveries` reads as Cars, and the other old categories read as Uncategorised. See [Addons](/using/addons).
- A new type, **Simplified**, marks mods merged into the game's shader packages, as the Simplified Suite loads `.serps` mods. Each row shows its category and types, as in **Cars · Archives, Simplified**, and the addon's panel has a **Type** row.
- Addons the Simplified Importer made are tagged **Imported**.

## For addon makers

- The `list-append` and `list-remove` database operations add a value to, or remove one from, a comma-separated list field such as an entrant setup mode's `entrant_lists`. Two addons appending to the same list don't conflict. See [Database operations](/reference/ops/database).
- The launcher checks its menu edits against the rules the game's UI loader applies, and stops the build on an edit the game would reject. The same check runs on any edited UI archive with `cargo run --release -p swofty-core --example ui_check -- <stock.erp>=<built.erp>`. See [Make a safe UI edit](/reference/ui/#make-a-safe-ui-edit).
- [UI engine internals](/reference/ui/engine) describes how the game builds a screen from its templates, what each node needs and what a rejected template takes down with it.
- `simplified` and `helmets` in a manifest need launcher 1.3.6.

## Fixes

- An addon that puts a whole archive and another addon's edits to resources in that archive no longer fail the build with "is replaced twice", as with an imported car pack that ships `teams/common.erp` and R&D: Tyres & Thermal Management. Load order decides which comes first, and the Addons page shows the overlap as a conflict.
- An addon that hides Choose Driver tabs switches them off the way the game does for a tab it doesn't offer, instead of building the header without them.

# 1.0.8

Swofty Launcher for F1 25 1.0.8 updates the offline play extension to v0.3.8, and teaches the addon system about EA-app builds of the game. Mod settings and addon features that need in-game hooks now resolve on those builds, where before only file mods did.

Download it from [Releases](https://github.com/Swofty-Developments/SwoftyLauncher/releases). The launcher offers each new release itself.

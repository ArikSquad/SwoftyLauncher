# 1.5.23

Swofty Launcher for F1 25 1.5.23 fixes the crashes and errors found in last night's Send Logs reports, and explains many more crashes in plain words.

## In game

- A Time Trial at a community track, such as Autopolis or Sochi, with a Classic Seasons car box no longer crashes as the session starts.
- On the EA app copy, F1 25 no longer closes a few seconds after it starts.
- Offline play no longer crashes F1 25 at start-up when Windhawk is running.

## Crash explanations

- When F1 25 freezes for 30 seconds and closes itself, the launcher says so, and names the addon or graphics mod that kept it busy when the log shows one.
- A crash from a track that fills F1 25's own memory, such as Sepang, names the track and says to turn it off or use a lighter profile.
- Windows running out of memory, Smart App Control blocking the mod loader, and RivaTuner (RTSS) crashes each get their own explanation with what to do.
- A graphics crash names the car packs that replace each other, and frame generation when it's on, instead of always blaming the graphics driver.
- Crashes on the EA app copy are explained like crashes on Steam.
- **Send Logs** on Windows includes the PC's memory and page file size.
- **Mods did not load** no longer shows on the EA app copy when the mods did load.

## Launcher

- When some of F1 25's own files are missing, files with a backup are put back. Otherwise Play stops and says to update F1 25 if it's out of date, or to verify the game files.
- An out-of-date F1 25 gets a warning before Play.
- An error about a missing or damaged file names the file and the addon it belongs to.
- A failed addon install no longer leaves a half-installed addon turned on, and a failed update keeps the version you had.
- Classic Seasons installed without any season addon says to install at least one.
- The track menu no longer stops Play with "slice … is past the end"; the missing pictures are filled with blank flags.
- The **Addon Browser** loads on slow connections and tries once more when the registry can't be reached.
- Removing an addon no longer fails with "Access is denied" while its page is open.
- The sidebar scrolls when its pages and addon panels don't fit the window.

## Addons

- **Classic Seasons** year addons 0.6.4 (already out): a Time Trial with the stock F1 2025 cars no longer loads every Classic Seasons year.

## For addon makers

- `.lng` language files whose `LNGT` header gives the wrong total size are read when their chunks end at the end of the file.

# 1.5.37

Swofty Launcher for F1 25 1.5.37 names a common addon crash and finds Proton in more Linux setups.

## Launcher

- When F1 25 crashes as a session loads with **F1 2012 Season** on, the crash screen and **Send Logs** name that addon and say to turn it off. The crash happens with and without Classic Seasons.
- On Linux, **Play** finds the Proton build Steam uses for F1 25 when the game has no Proton choice of its own (Steam's default applies), when Steam names a bundled Proton differently from its folder, and when Proton is in another Steam library than the game. When it still can't find it, the error lists the folders it searched.

# 1.2.4

Swofty Launcher for F1 25 1.2.4 checks that your game is the copy Steam installed before it builds or changes anything.

Steam keeps a list of every file it installed for F1 25, with its size and hash. When you press **Play**, the launcher compares the game against that list. If a file was changed outside the launcher, for example by another mod tool or a manual install, F1 25 is not started and a **Your game files aren't the ones Steam installed** dialog names the files. In Steam, right-click F1 25 → **Properties** → **Installed Files** → **Verify integrity of game files**, then press **Play** again. See [If your game files aren't the ones Steam installed](/guide/windows#if-your-game-files-aren-t-the-ones-steam-installed).

The launcher also checks the original game files it backed up earlier. Before, it accepted whatever was in the game folder the first time it backed a file up, so a file another tool had already changed became the launcher's "original" for good, and a track could fail with an error such as `tracks.flags_circle: slice 35 is past the end`. A backup that doesn't match Steam's copy now asks you to verify the game files; once you have, the next launch backs up Steam's copy instead and carries on.

The first launch after the update compares the backups the launcher already holds with Steam's list, which takes a few seconds. Files Steam doesn't list, such as other tools' extra files, are not checked. A game folder outside Steam, or one whose Steam list can't be read, is not checked, and the launch log says when the list can't be read.

Download it from [Releases](https://github.com/Swofty-Developments/SwoftyLauncher/releases) or with the [installer](/guide/installation). The launcher offers each new release itself.

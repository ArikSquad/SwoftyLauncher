# 1.4.0

Swofty Launcher for F1 25 1.4.0 adds the **Addon Browser**: community addons you can search, star and install in a click, published by creators at [publish.f1.swofty.net](https://publish.f1.swofty.net) and reviewed before they're listed. Swofty's own addons move there too. It also installs addons from rar archives, adds a file picker to **Install addon**, adds shader packs, and makes menus and builds faster.

## Addon Browser

A new **Addon Browser** page lists the addons creators publish. See [Addon Browser](/using/addon-browser).

- **Categories** across the top: All, Seasons, Tracks, Cars, Helmets, Shaders and Other, each with its count.
- **Search** across names, ids, creators, categories, types and descriptions. It tolerates a typo in longer words, takes `author:` and `category:`, highlights what matched, and shows matching creators above the addons.
- **Sort** by Most stars, Most downloads, Trending, Recently updated, Newest or Name. While you search, the order is Best match.
- **Filters** for type, state (installed, not installed, update available, starred by you, works with this launcher), creator, and **Hide addons that run code**.
- **Cards** show the icon, creator, summary, stars, downloads, downloads this month, when it was updated, its category and types, and a **Runs code in the game** tag for addons with native code.
- **Details** show the description, a 30-day downloads chart, stats (stars, downloads, size, updated, first published, the launcher version it needs, the SHA-256), the creator, and every version with its date, size and changelog.
- **Install** downloads the newest version that works with your launcher, checks its size and SHA-256, installs it switched off and opens the **Addons** page with it highlighted. Progress shows each stage: downloading with speed, verifying, installing. A failed install stays on the card with its reason and **Retry**.
- **Stars:** star an addon from its card or details. Your stars sync with the server and follow you across networks; each person counts once per addon.
- **Creators:** select a creator's name, or open **Creators**, for their page: avatar, bio, links, totals and every addon they publish. An addon's details list **More from** the same creator.
- **Addons page:** an installed addon that's in the browser shows its creator, stars and downloads, more from its creator, and **View in Addon Browser**. The first install card is now **Looking for a Swofty Addon?**.
- **Activity** lists the last 50 catalog refreshes, star syncs, installs and updates. Offline, the page shows the addons from the last refresh. Everything is also written to `state/registry.log`, which Send Logs includes.

## Addon updates on the Play button

When an addon from the Addon Browser has a newer version that works with your launcher, **Play** becomes **Update addons** with the number of updates. The launcher checks when it opens and every 30 minutes. A notification lists what updated and anything that failed. See [Updating](/using/updating#addon-updates).

## Swofty's addons

The Career Mode Editor, Driver Manager, R&D: Tyres & Thermal Management and F1 25 RE-Optimization are now in the Addon Browser, published by Swofty. Releases no longer carry an `addons/` folder: updating to 1.4.0 removes it, and the copies you have installed stay installed and update from the Addon Browser. SwoftyMod stays built in, and Simplified for Swofty keeps its own updater. See [Swofty's addons](/using/swofty-addons).

## Installing addons

- **Install addon** is a menu with **Choose a file** and **Choose a folder**, so zips, rars and `.swoftyaddon` packages can be picked on Windows too.
- A rar installs like a zip. Addon folders and `.swoftyaddon` packages up to three folders deep in a zip or rar each install as an addon. A rar without one still goes to the importer that claims it.
- On Windows, the launcher warns once when it runs as administrator, since Windows blocks drag and drop from Explorer into it. Send Logs records it in `summary.txt`.

## Driver Manager 0.1.2

- **Set for every driver** gives one rating or AI trait the same value on all your drivers, or on free agents only.
- **Game drivers** sets the head and helmet of the game's own drivers, including heads and helmets other addons install.
- The Linux helper runs on every distribution.

Update it from the Addon Browser. See [Driver Manager](/using/driver-manager).

## DB Editor

- A **Race weekends** page can move a weekend to a modded track.
- A field's **All rows** menu sets the selected row's value, or the field's minimum or maximum, on every row the page lists. Search first to narrow it.

## Shader packs

A shader pack grades the picture with a `.cube` LUT, applied to the game's tonemap each frame. It's an experimental feature: a pack lists the `shaders` feature and the `shaders` category, a choice can pick the look and a slider its strength, and the last shader pack in the load order wins. The Addons page lists them under **Shaders**. See [Shader packs](/reference/addons/shader-packs) and the new `templates/shader-pack` with three looks.

## Faster

- In menus, pause screens and sessions, the core reads the career only around flow changes instead of every 250 ms. On Windows that read took about 12 ms, so four frames a second ran long.
- Building reads and writes the game database and LZ4 archives faster, and decoding textures copies less.

## Send Logs to Developers

Send Logs uploads to `api.f1.swofty.net`, which posts the report to the developers' channel. The launcher no longer contains a Discord webhook. See [Send your logs to the developers](/using/send-logs).

## For addon makers

- Publish at [publish.f1.swofty.net](https://publish.f1.swofty.net) with the **Swofty Launcher Addon Creator** role from the [Swofty Discord](https://discord.swofty.net): sign in with Discord, drop your zip for a preview, add a changelog and publish. Each version is reviewed before it's listed, and you can follow its status, edit your description, yank versions and set your creator profile there.
- The first account to publish an id owns it, versions only go up, and `swofty.` ids are reserved.
- The build checks each add-row copy for data the game finds through the row's label in other tables and files, and warns per addon when it's missing. `swofty build --side-data` lists every match.

# 1.5.31

Swofty Launcher for F1 25 1.5.31 fixes a crash at startup with team packs built on an older game database and stops with a clear message when the game folder is missing its anti-cheat launcher.

## Launcher

- A team pack built on an older F1 25 database, such as some RM Designs packs, no longer makes F1 25 crash at startup.
- When `EAAntiCheat.GameServiceLauncher.exe` is missing from the game folder, **Play** stops and says to verify the game files in Steam or repair F1 25 in the EA app, instead of F1 25 showing "Game launch error 0x00000004".
- **Send Logs** names an error F1 25 hits while it closes as a fault in the game's shutdown, not a crash, and says when the game ran out of memory while saving a career.
- The [installation guide](/guide/installation#moving-the-data-folder) shows how to keep the data folder on another drive with `SWOFTY_DATA_DIR`.

## Addons

- **Career Mode Editor 0.3.6:** the Calendar page says why **Repair the round count** isn't offered while the season's race dates aren't readable, and that rounds can be replaced or moved but not removed.
- **Any Team Transfers 0.1.1:** every team makes offers in careers loaded from a save.

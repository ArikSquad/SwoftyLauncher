# 1.3.2

Swofty Launcher for F1 25 1.3.2 gives addons 39 more game bindings. Each one was verified independently against F1 25's executable.

## New bindings

- **Career contracts:** building, signing and checking a driver's contract, the negotiation decision, the contract intro, update and outro flow states, and the flow's continue and stay links.
- **Sessions:** a session group's results, row positions and recorded times, the tyre allocation's session start, the closest available compound lookup, the session tyre rules, and the tyre component type.
- **Game:** engine wear and grid penalties, R&D upgrade progress and a vehicle's upgrades, the career's track list (its preset, calendar entries, descriptor and vtable), the career setup's settings screen, and the back routes of the career setup and driver select screens.
- **Core:** finding a component on an entity, the root of the game's type tree, the game root, full-screen video playback, and the call site after a replay records.

See the [Game API](/reference/game/) for each binding's name, signature and status.

## Other changes

- The Game API reference lists every binding the core ships: 338 in all, across 11 subsystems.

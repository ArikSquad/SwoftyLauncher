# 1.2.6

Swofty Launcher for F1 25 1.2.6 updates the offline play extension to v0.3.11, and completes the addon system's support for EA-app builds of the game. Mod settings and addon features that need in-game hooks now resolve on those builds.

Download it from [Releases](https://github.com/Swofty-Developments/SwoftyLauncher/releases). The launcher offers each new release itself.

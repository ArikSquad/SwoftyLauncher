# 1.5.9

Swofty Launcher for F1 25 1.5.9 makes addon pages with long tables smooth. TeamSimplified contributed the change.

## Addons

- An addon page with a long table, such as a list of 80 drivers with a form in each row's panel, no longer lags on hover, search, sort, filter or scroll.
- A table with more than 30 rows draws only the rows in and near view.
- A form in a row's panel is set up when the panel opens. Values typed in it but not sent are lost when the panel closes.
- An addon's page of blocks scrolls smoothly with the mouse wheel, as the Addons and Addon Browser pages do.
- Addon authors: see [Row details](/reference/addons/launcher-api#row-details).

## Tracks

- A database mod made from a whole game database, such as RM Designs' team packs, no longer takes community tracks out of Grand Prix track lists or undoes their other database changes. The build log names the addon. See [Installing tracks](/reference/installing-tracks).

## Linux

- Proton sessions load Swofty's loader even when the Wine prefix doesn't set the version.dll override. Those sessions ran without addon lists, the Addons Manager and other runtime features.

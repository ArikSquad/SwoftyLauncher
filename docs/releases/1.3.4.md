# 1.3.4

Swofty Launcher for F1 25 1.3.4 lets the DB Editor give a driver their own ratings by copying someone else's.

## DB Editor

- Values that come from the game default show **Copy from…**. Pick a driver, or **Game default**, and their whole row is copied to this driver. The values become ordinary edits with **Revert**. See [DB Editor](/using/db-editor).
- The copied group says whose row it came from and has **Remove own row**, which takes the row out with its edits. **All changes** lists copied rows.
- `swofty db copy-row` and `swofty db remove-row` do the same from the command line. See [`swofty db`](/reference/cli#swofty-db).
- An addon with copied rows needs launcher 1.3.4 or newer.

## Other changes

- Addons get three more game bindings, for adding Grand Prix and Time Trial category boxes (era select). See the [Game API](/reference/game/).
- A database edit of a stock value such as `-1` in an unsigned 64-bit field now applies. It was dropped before, and a game mode copied with it could crash F1 25 at load.

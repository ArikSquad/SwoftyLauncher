# 1.5.12

Swofty Launcher for F1 25 1.5.12 makes heads from face mods usable.

## Addons

- A mod that adds a driver head the game doesn't have, such as a face mod with a `heads/<name>.erp` archive, gets a driver head row and its asset groups when the profile builds, so drivers can wear the head. Before, the head's files went into the game folder and nothing in the game used them. A mod you imported before this release works without importing it again. See [Face mods](/using/mods#face-mods).
- [Driver Manager](/using/driver-manager) 0.1.3 offers these heads for new drivers and for the game's drivers, with the mod's name after the head. Update it from the Addon Browser.
- The DB Editor's **Head model** choices on **Drivers** and **Characters** list them too. See [Heads from addons](/using/db-editor#heads-from-addons).
- A driver whose head comes from a mod that's turned off keeps the game's head, and the launch log names the addon that picked it.

## Addon developers

- A `file.put` of a head archive whose label no driver head row has adds the row and registers the groups. See [Driver heads](/reference/addons/runtime-assets#driver-heads).
- The `profile_heads` host call lists the heads the profile's addons put. See [Profile heads](/reference/addons/launcher-api#profile-heads).

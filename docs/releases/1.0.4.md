# 1.0.4

Swofty Launcher for F1 25 1.0.4 manages the Team Simplified addon for you. The built-in copy is gone; the launcher now pulls Simplified for Swofty from Team Simplified's own releases, checks for a newer one on startup and every few hours, verifies its SHA-256 before installing, and keeps it on and non-removable on the Addons page. Your mod library and each profile's mod order carry over unchanged, because the addon keeps the same id.

Download it from [Releases](https://github.com/Swofty-Developments/SwoftyLauncher/releases). The launcher offers each new release itself.

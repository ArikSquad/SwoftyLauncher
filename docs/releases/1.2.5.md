# 1.2.5

Swofty Launcher for F1 25 1.2.5 lists addons that only add tracks with the tracks.

An addon whose only changes are adding tracks and giving them names, the kind described in [A track with its own name](/reference/data/track-names), is no longer listed on the **Addons** page while your profile has a **Tracks** page, which [Simplified for Swofty](https://github.com/TeamSimplified/simplified-swofty-addon) 0.6.0 adds. You switch it on and off and remove it on the **Tracks** page, next to your track packages. The **Addons** page says how many track addons are on the Tracks page and has an **Open Tracks** link. An addon that adds a track and also changes other things, or has code, settings or save data, stays on the **Addons** page. Without a Tracks page, every addon stays on the **Addons** page.

For addon authors: `swofty_core::tracks::is_track_addon` tells whether an installed addon counts as a track addon.

Download it from [Releases](https://github.com/Swofty-Developments/SwoftyLauncher/releases) or with the [installer](/guide/installation). The launcher offers each new release itself.

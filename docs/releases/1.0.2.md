# 1.0.2

Swofty Launcher for F1 25 1.0.2 lists every enabled mod in the in-game **ADDON SETTINGS** screen. Until now it showed a tile for each addon and each track; it now adds a tile for every other enabled mod as well, such as the liveries and packages in the Team Simplified Suite. A mod's tile opens a page with its id, author and version, so **ADDON SETTINGS** is the one place in game to see everything a profile turns on. Mods are read-only there; turn one on or off from the addon's row on the launcher's **Addons** page.

Download it from [Releases](https://github.com/Swofty-Developments/SwoftyLauncher/releases). The launcher offers each new release itself.

# 0.2.10

Swofty Launcher for F1 25 0.2.10 updates the offline play extension to v0.3.5. Fresh installs of 0.2.9 could fail to verify the downloaded extension; this release fixes that.

Download it from [Releases](https://github.com/Swofty-Developments/SwoftyLauncher/releases). The launcher offers each new release itself.

# 1.5.34

Swofty Launcher for F1 25 1.5.34 fixes the crash at startup with team packs built on an older game database and a folder error after moving the data folder.

## Launcher

- A team pack built on an older F1 25 database, such as RM Designs and APXgp packs, no longer makes F1 25 crash at startup. The build keeps the entrant lists as the pack leaves them and warns that F2 menus may crash with that pack.
- After moving the data folder, a file or broken link left where the Addon Browser keeps its downloads no longer stops it with "cannot create a file when that file already exists". The launcher moves the file aside and makes the folder again.

# 1.5.38

Swofty Launcher for F1 25 1.5.38 finds system-installed Proton builds on Linux and explains an antivirus blocking offline play.

## Launcher

- On Linux, **Play** also looks for Proton in `/usr/share/steam/compatibilitytools.d`, `/usr/local/share/steam/compatibilitytools.d` and the folders in `STEAM_EXTRA_COMPAT_TOOLS_PATHS`, where package managers install builds such as Proton-CachyOS and Proton-GE.
- When an antivirus removes or blocks the offline play files while the launcher downloads or installs them, **Play** says so and names the folders to add as exclusions, instead of showing a Windows error code.

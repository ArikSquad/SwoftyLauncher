# 0.2.2

Swofty Launcher for F1 25 0.2.2 updates the offline play extension to 0.2.3. A game build the extension does not recognise now reports the exact stage that failed, and the resolver accepts more of the ways compilers encode the same code, so supported builds stop being refused over encoding details.

Download it from [Releases](https://github.com/Swofty-Developments/SwoftyLauncher/releases). The launcher offers each new release itself.

## Offline play

- The offline play extension is version 0.2.3. When a session is refused, the report fingerprints the game build (size, PE timestamp, sections) and names the stage that failed: the anchor string, its code reference, or the gating branch. One launcher log is then enough to see what differs in a build.
- The resolver matches `lea` with every REX prefix and the bare 32-bit form, accepts `test rax,rax` next to `test eax,eax`, and searches four times farther back from the code reference for the gating branch. A build that encodes the same code slightly differently is no longer refused.
- Branch shapes the extension cannot patch with a single byte, such as near or inverted jumps, are reported by name instead of being guessed at. Sessions on unknown builds are still refused; the extension fails closed.

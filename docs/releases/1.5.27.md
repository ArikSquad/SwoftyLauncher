# 1.5.27

Swofty Launcher for F1 25 1.5.27 repairs Simplified for Swofty after an antivirus removes its helper, keeps the track menus with community tracks, and gives addons a fuller in-game overlay and an ADDONS page in the race MFD.

## Launcher

- When an antivirus removes Simplified for Swofty's helper program, **Play** downloads the same version of Simplified for Swofty again before it builds. When another addon's helper program is gone, the error names the addon and says to allow its folder in the antivirus.
- An addon change to a game file that isn't in F1 25 is skipped with a warning naming the addon, and the build carries on.
- With a community track in the profile, an addon that ships its own track menu pictures no longer replaces the launcher's track menus. The build warns and lists the pair in the conflicts.
- When F1 25 stays on its start screen with BP Ultimate Livery on, the launcher says F1 25 got stuck and names the addon to turn off.
- Post-processing addons such as PolyphoniX build their passes on the game's own graphics device, so they can't stop the game with DLSS Frame Generation on.

## Progressive Career

- Choose Driver and Team Select show the start season's race numbers, from Progressive Career's next update.

## For addon makers

- The in-game overlay draws rounded rectangles, gradients, circles, arcs, lines and polygons, styled text with alignment and wrapping, and images and nine-slice panels.
- An overlay can take input focus and read the mouse and keyboard. `swofty/overlay_ui.hpp` adds panels, labels, buttons, toggles, sliders, lists, text fields and toasts.
- `hud.mfd` in the manifest puts up to 8 of an addon's toggle and choice options on an ADDONS page of the race MFD.

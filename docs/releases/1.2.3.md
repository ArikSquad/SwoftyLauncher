# 1.2.3

Swofty Launcher for F1 25 1.2.3 lets an addon that supports only one career mode keep players out of the other, with the game's own message popup.

**R&D: Tyres & Thermal Management** 0.11.0 works in Driver Career only and blocks My Team. Pressing **MY TEAM CAREER** on the Career menu shows a **My Team not available** popup that says to turn the addon off, or use a profile without it, to play My Team; after **Okay** the Career menu is back. With 0.10.0, starting or loading a My Team career froze the game for about 30 seconds until the game closed itself. Driver Career is unchanged.

An addon blocks a mode with `swofty::career::block(mode, title, body)`. swofty_core runs every Career menu route through the game's route runner, fires `career.starting` with the mode and route before anything of the career loads, and cancels the route when an addon blocks that mode. The player stays on the screen they pressed on. See [Blocking a career mode](/reference/std/career#blocking-a-career-mode).

The new [Popup](/reference/std/popup) library shows the game's message popup with an addon's own title and body, from any thread. Each popup carries its own text; no language strings change.

Launcher plugins can list, install, turn on and off, and remove other addons through four new host calls, listed in `hello.host_calls`. A plugin can't remove itself, a built-in addon or one the launcher manages, and can't turn off or remove an addon that keeps data in your saves; those stay on the **Addons** page, which warns first. See [Launcher API](/reference/addons/launcher-api).

[Simplified for Swofty](https://github.com/TeamSimplified/simplified-swofty-addon) 0.6.0 uses them in its **Tracks** section: data addons that add a track now appear there with track packages, with their switch and **Remove**, and the file picker installs them. With an older launcher the section lists track packages only.

For addon authors: the addon API is at version 7 (swofty_core 0.2.12), with the `popup` table and `block`, `unblock` and `career.starting` in `career`.

Download it from [Releases](https://github.com/Swofty-Developments/SwoftyLauncher/releases) or with the [installer](/guide/installation). The launcher offers each new release itself.

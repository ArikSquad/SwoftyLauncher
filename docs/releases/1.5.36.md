# 1.5.36

Swofty Launcher for F1 25 1.5.36 stops Play less often on game files it can prove are Steam's own.

## Launcher

- When a game file the profile replaces differs from the original the launcher recorded, **Play** compares it with Steam's copy. A file that matches is recorded as the original and the build carries on. A file that doesn't match stops Play with a message to verify the game files in Steam, instead of saying it might be a mod copied in by hand. EA app copies keep the old check.
- **Send Logs** includes the record of a blocked Play, and the build log names the size, date and hash of the file that blocked it.

# 1.5.2

Swofty Launcher for F1 25 1.5.2 fixes the game stopping a few seconds after an addon drew over it, such as Manual Pit Lane's messages or Canned DNFs + Safety Car. An addon made for a newer launcher no longer stops the launcher from loading addons, and the Addon Browser opens on category tiles.

## Addons that draw over the game

- The game no longer stops shortly after an addon draws over it with DLSS Frame Generation or XeSS Frame Generation loaded. These crashes came from your Send Logs reports.
- Drawing goes only to the picture the game presents, on the queue the game presents with. SwoftyMod no longer holds the game's frame buffers or hooks window resizes.
- While frame generation is on in the game's settings, nothing is drawn over the game. The addons keep running.
- When the graphics card stops responding shortly after something was drawn, drawing stops for the rest of that session.
- The Addons list tags an addon **Draws over the game** or **Changes the picture**, and its panel has an **In game** row. See [Addons](/using/addons#find-an-addon).
- **Send Logs** lists the addons that draw over the game and whether they drew in each session.

## Addons from newer launchers

- An addon made for a newer Swofty Launcher, or one whose `swofty.json` is damaged, no longer stops the launcher and every `swofty` command. It's listed under **Can't be used** with the reason, and builds leave it out. See [Addons that can't be used](/using/addons#addons-that-can-t-be-used).
- A profile with settings from a newer launcher still loads, and keeps those settings.

## Addon Browser

- The Addon Browser opens on a tile for each category: Seasons, Tracks, Cars, Helmets, Shaders and Other. Each tile shows how many addons it holds and the icons of its most starred addons.
- **All addons** below the tiles lists every addon, and **Categories** above the list goes back to the tiles. See [Addon Browser](/using/addon-browser).

## For addon makers

- `SWOFTY_FRAME_CAPTURE=<folder>` writes the presented frame, overlay included, to PNG files, and `SWOFTY_KEEP_FOCUS=1` keeps the game running when its window loses focus. See [Logging](/reference/std/logging).

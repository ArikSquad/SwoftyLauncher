# 1.0.3

Swofty Launcher for F1 25 1.0.3 updates the offline play extension to v0.3.6, with compatibility improvements for EA-app builds. Session logs now also keep a complete copy of the session story in the game folder.

Download it from [Releases](https://github.com/Swofty-Developments/SwoftyLauncher/releases). The launcher offers each new release itself.

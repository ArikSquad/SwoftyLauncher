# 1.3.5

Swofty Launcher for F1 25 1.3.5 lets you send your logs zip to anyone, such as a track's author, and fixes the Career Mode Editor page saying F1 25 is closed while you're in a career.

## Send Logs

- **Send Logs to Developers** keeps the logs zip in the data folder's `logs` folder, the newest 10. After sending, the dialog says **You can also send your logs manually for debugging** with a link that opens the zip in File Explorer or your file manager, ready to drag into Discord. See [Sending your logs](/using/send-logs).
- When sending fails, the same link shows under the error.
- In a build that can't send logs, the sidebar has **Save Logs**, which saves the zip and shows the link.
- `swofty logs send` prints where it kept the zip.

## Career Mode Editor 0.2.4

- The page shows your My Team or Driver Career and its edits whenever the game reports it, even when the launcher's own check says F1 25 isn't running. Closing the game still shows **F1 25 isn't running** straight away.
- The page writes what it sees to its log, which **Send Logs to Developers** includes.
- The Linux page runs on every distribution, not only the one it was built on.
- Installed copies update to 0.2.4 with the launcher. See [Career Mode Editor](/using/career-editor).

## Other changes

- On Windows the launcher finds a running F1 25 from the Windows process list instead of `tasklist`, so the play bar and the Career Mode Editor see the game on PCs where `tasklist` returns nothing.
- Addons get two more game bindings for the F1 World activity screen and its entrant list selection. See the [Game API](/reference/game/).

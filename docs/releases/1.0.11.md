# 1.0.11

Swofty Launcher for F1 25 1.0.11 starts offline play on the Steam Deck and other Linux distributions. Launches stopped with `f1op-probe-linux-x86_64: No such file or directory` there: the offline play extension's Linux tools ask for a system loader that most distributions don't have. The launcher now runs them through the system's own loader, and says which loader is missing when it can't.

The offline play extension now installs as a whole or not at all. A failed download reports the network error, the HTTP status, a missing file, a cut-off download or a checksum mismatch. `swofty offline status` shows how the extension's tools run.

Download it from [Releases](https://github.com/Swofty-Developments/SwoftyLauncher/releases) or with the [installer](/guide/installation). The launcher offers each new release itself.

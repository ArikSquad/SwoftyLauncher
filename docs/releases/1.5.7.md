# 1.5.7

Swofty Launcher for F1 25 1.5.7 lets the DB Editor use the drivers you make in Driver Manager.

## DB Editor

- The choices of a field that picks a driver or an entrant also list Driver Manager's drivers, such as **Jacob Swofty (Driver Manager)**. That puts one in a seat on **Line-ups**: the grid of Grand Prix, Time Trial and careers started after the change. See [Driver Manager drivers](/using/db-editor#driver-manager-drivers).
- Search finds Driver Manager's drivers by name, code and label, such as `dm_208`. Picking one opens the **Driver Manager** page, where they're edited.
- When a DB Editor addon picks a Driver Manager driver and Driver Manager is off, or doesn't add that driver, the launch log names the addon and the driver. **Export game files** names them too.
- `swofty db search`, `get` and `set` do the same from the command line.

# 1.5.20

Swofty Launcher for F1 25 1.5.20 fixes addons going missing when you play the same profile again.

## Launcher

- Pressing **Play** again on a profile you haven't changed no longer starts F1 25 without **ADDON SETTINGS**, the code of addons such as Classic Seasons, and addons' runtime assets. The first Play after updating rebuilds each profile once.

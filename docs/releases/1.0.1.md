# 1.0.1

Swofty Launcher for F1 25 1.0.1 drops the `capabilities` list on a native plugin's `operations.native` entry. It was checked against a known set of names but did nothing: the in-game loader never read it, it gated nothing, and it did not control the experimental-feature switch (that is `"features"` in `swofty/assets.json`). Addons that still declare it load as before; declaring it now has no effect, and it is gone from the documentation and the template.

Download it from [Releases](https://github.com/Swofty-Developments/SwoftyLauncher/releases). The launcher offers each new release itself.

# 1.0.9

Swofty Launcher for F1 25 1.0.9 checks for a new launcher and a new Simplified for Swofty when it opens and every minute after. When either has a release, **Play** becomes **Update**: one click installs Simplified for Swofty, then the launcher, and restarts it. If you're offline or GitHub is unreachable, **Play** stays. See [Updating](/using/updating).

1.0.9 is the first release to ship [F1 25 RE-Optimization](/using/bundled-addons), xanpavle's renderer optimisation, as a bundled addon. Updating installs it, and it stays off in every profile until you turn it on. You can also remove it from the **Addons** page.

On Windows, a modded launch stops with an explanation when `F1_25.exe` is set to run as administrator and the launcher isn't, instead of failing with exit code 1. `swofty doctor` reports the setting.

For addon authors: an addon whose `compat.launcher` range the launcher doesn't satisfy no longer installs, and a profile that enables it doesn't build. A plugin can bind a game function that another plugin has already hooked. Sites inside `.data1` bodies can be bound when the knowledge base records them, and a session can hold 256 sites. `tools/pack_addon.py --zip` packages an addon as a `.zip`, which the launcher installs like a `.swoftyaddon`.

The [R&D: Tyres & Thermal Management](https://github.com/Swofty-Developments/SwoftyLauncher/tree/main/addons/rnd-tyres-thermal) addon 0.10.0 needs this release.

Download it from [Releases](https://github.com/Swofty-Developments/SwoftyLauncher/releases) or with the [installer](/guide/installation). The launcher offers each new release itself.

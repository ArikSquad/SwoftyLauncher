# 1.0.5

Swofty Launcher for F1 25 1.0.5 adds a runtime binding resolver: the loader can locate engine functions from live memory using string anchors, alongside the per-build signatures it already carries. The EA App build of F1 25 now writes self-diagnostics to a dedicated `ea-diagnostics.log` next to the loader log — the startup gates it reaches, where any crash lands, and whether each engine binding resolves. The diagnostics stay dormant on the Steam build.

Download it from [Releases](https://github.com/Swofty-Developments/SwoftyLauncher/releases). The launcher offers each new release itself.

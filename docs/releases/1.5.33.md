# 1.5.33

Swofty Launcher for F1 25 1.5.33 keeps every database change in large addon profiles and explains when Windows blocks one of the launcher's programs.

## Launcher

- A profile whose addons add close to 100,000 database records, such as Progressive Career with every Classic Seasons year, no longer loses all its database changes in game. Before, Progressive Career and the season cars could be missing from the menus.
- When Windows denies starting `swofty.exe` or another of the launcher's programs, the error says an antivirus or Controlled folder access most likely blocked it and names the folder to allow.

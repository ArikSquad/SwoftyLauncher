# 1.0.6

Swofty Launcher for F1 25 1.0.6 brings offline play to the EA App build. That build carries a second activation gate in `Core/Activation64.dll` that quietly exited the game with code -1 a few seconds into launch; offline play v0.3.7 resolves it by signature and flips it, so an EA App session continues into the game the way the Steam build already did. Restore now retries files that Windows holds locked — an antivirus scanning the game folder is the usual cause — and names the locker when it still cannot, so a session returns the folder to vanilla. The EA self-diagnostics now pinpoint the activation and exit gates in the running `Activation64.dll` and whether each one is patched.

Download it from [Releases](https://github.com/Swofty-Developments/SwoftyLauncher/releases). The launcher offers each new release itself.

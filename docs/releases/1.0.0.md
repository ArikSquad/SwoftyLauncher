# 1.0.0

Swofty Launcher for F1 25 reaches 1.0.0.

## A redesigned launcher

The window has a new look: the Swofty Launcher wordmark in the sidebar, a cooler palette, the active profile picker moved into the sidebar, and a bottom bar that shows the game's real version, the F1 25 cover art, and a Play button that can launch with the console attached. A third-party addon's panel now has a **Remove** button that deletes it and takes it out of every profile, and rows on an addon's page carry a right-click menu.

## The native standard library

Engine plugins reach five standard libraries through `SwoftyApi` at API version 5: **events** and a frame scheduler, an **overlay** draw API over the game's D3D12 present, **telemetry** reads and a shared feed, **database** reads, and sandboxed **storage**. Each one is a table on `SwoftyApi` with a C++ wrapper header, and declares whether it is on through `available()`.

## Addons as helper programs

An addon's launcher-side part can now be a prebuilt **helper program**, one per operating system, named in the manifest's `launcher.program`. The launcher runs it as a subprocess and talks newline-delimited JSON, so the helper can be written in any language. It can read the game's own files during import and build through host calls, and the rest of the launcher still sees it as a normal addon.

## Documentation

The documentation is rewritten around two audiences — **Users** and **Developers** — with a sequenced path through installing, using, making a mod, and making an addon, and one home for the standard library. Read it at [f1.swofty.net](https://f1.swofty.net).

Download 1.0.0 from [Releases](https://github.com/Swofty-Developments/SwoftyLauncher/releases). The launcher offers each new release itself.

# 1.0.7

Swofty Launcher for F1 25 1.0.7 puts the game folder back to vanilla however a session ends: a normal quit, a crash, Steam's **Stop**, a closed terminal or a killed launcher. The session holds a lock until its files are rolled back, and the next launcher start, `swofty run` or `swofty apply` rolls back anything an unfinished session left and says **Recovered the game folder from an unfinished session**. Files of unknown origin that stop a launch are moved to `$DATA/set-aside/<time>/` instead of being deleted, and the game's own logs move out of the game folder into the session's folder. You no longer need `swofty restore` after a crash.

Profiles can be deleted from the launcher's profile list or with `swofty profile delete <name>`. Resource replacements that change an archive's stock layout now reach the game: the launcher rewrites those archives instead of dropping the replacement, which addons that add menu scenes, textures or icon frames rely on.

Every release now ships [Swofty UI](/reference/ui/swofty-ui) as `bin/swofty-ui`, a viewer and editor for the game's menu scenes (`.idf` files) that resolves scene references by their `xref` id, as the game does. The new [installer](/guide/installation#install-with-the-installer) asks for a folder, installs the latest release with Start menu or app menu shortcuts, and opens the launcher. New reference pages cover [UI modding techniques](/reference/ui/techniques) and [live debugging](/reference/ui/debugging).

Download it from [Releases](https://github.com/Swofty-Developments/SwoftyLauncher/releases) or with the [installer](/guide/installation). The launcher offers each new release itself.

# 1.5.11

Swofty Launcher for F1 25 1.5.11 fixes a crash at boot with large addon lists.

## Addons

- A profile whose addons add more than about 90,000 database records, such as several Classic Seasons year addons with community tracks, starts the game instead of crashing about 4 seconds in, before any menu. The game's database grows at 838,860 records, and growing it after the game has loaded crashed the game. The build now puts such a database into the game file, which the game loads in full, and the build log has a `database: built into the game file` line with the counts. See [the CLI reference](/reference/cli).
- If database edits that would grow the game's database still reach the game, Swofty applies none of them and the game starts with its own database. The game log has a `gamedb` line with the counts.

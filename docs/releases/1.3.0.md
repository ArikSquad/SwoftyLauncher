# 1.3.0

Swofty Launcher for F1 25 1.3.0 makes everything an addon. Mods, tracks and database changes use the Swofty addon format, so they install, switch on and off per profile, and stack in one load order.

## Sidebar

The sidebar has five sections: **News**, **Addons**, **Mod Importer**, **Tools** and **Profiles**. Below them, **ADDON PANELS** lists the DB Editor and the pages addons add, such as the Career Mode Editor. An addon can give each of its pages its own sidebar icon with `sections/<id>.svg`.

## News

**News** opens first. It shows the Discord invite, the latest news in full, and the changelog of every release. See [News](/using/news).

## Addons

The **Addons** page lists every addon in load order, with search and filters by category, type, source and state. Drag an addon to change its place; the lower one wins when two change the same thing. Each addon's panel shows what it changes and which addons it overrides or is overridden by. **Check conflicts** builds the profile without starting the game and updates that list. **Turn off all** turns off every addon you can turn off. See [Addons](/using/addons).

Dropping a file that isn't an addon opens a dialog that points to the Mod Importer for mods and to the addon docs for addon makers.

## Mod Importer

The **Mod Importer**, made with Team Simplified, turns a mod into a Swofty addon: zips, 7z and RAR archives, folders, `.serps` packages, community tracks and modded game databases. Its database records, text, archive resources, team logos, files and tracks become the addon's operations. A mod made of alternative variants installs every variant with one turned on. Mods in the old Mods library convert the first time 1.3.0 starts, in each profile's order and with the same switches, in a dialog that lists each mod as it converts. Each conversion writes a log that **Send Logs to Developers** includes. See [Mod Importer](/using/mods).

## DB Editor

The **DB Editor** edits F1 25's game database: drivers, teams, line-ups, cars, engines, tyres, tracks, track settings, the calendar, weather, points, game modes and 20 more pages, plus every table and key under **All tables**. **Save as Addon** saves your changes as an addon on the Addons page. **Export** shares an addon as a zip or as game files for players without the launcher. **Import** reads DB Editor addons, EGO GameDatabases Editor exports of modified records and modded `gamedatabases.2025.bin` files. See [DB Editor](/using/db-editor).

## Tools

**Tools** shows other programs for making F1 25 mods: Team Simplified's Simplified Suite and PavelGames' EGO GameDatabases Editor.

## EA app

Pressing **Play** on the EA app version of F1 25 explains that only the Steam version is supported for now. `swofty run` and `swofty apply` stop with the same message.

## F1 25 RE-Optimization 0.2.5

The bundled [F1 25 RE-Optimization](/using/bundled-addons) addon updates to xanpavle's 0.2.5. Its tuned values hold inside the engine after the graphics preset applies, FSR 3 engages instead of falling back to TAA, and the ray-traced ambient occlusion and DDGI passes are off by default. A new **Enforce mode** setting chooses Cheaper (the default), Target or Off. It has a new icon.

## Other changes

- `swofty conflicts` shows the profile's conflicts; `--check` builds it first.
- `swofty db` edits DB Editor addons from the command line.
- The build log lists what each addon changes and one line per conflict between two addons.
- Only one build of a profile runs at a time.
- `swofty` addon commands accept relative paths, and the CLI uses the game folder picked with **Locate F1 25** before Steam's.
- Page footers scroll with the page.

For addon authors:

- `swofty.json` takes `category` and `origin`, and `kind` takes `text`. See [the manifest](/reference/addons/manifest).
- Database operations: an addon from the DB Editor applies leniently; a change that no longer applies is skipped with a warning.
- ERP operations: `merge-slices` merges texture-array slices over the resource in place. See [ERP operations](/reference/ops/erp).
- Text operations: `lang.default` sets a string any `lang.set` overrides. See [Text](/reference/data/text).
- Launcher API: the `startup` event, the `show_addon` effect with an optional notice, the `move_addon` and `tasks` host calls, and `position` in `addons`. See [Launcher plugins](/reference/addons/launcher-api).
- `swofty_addon::builder::AddonBuilder` writes data addon folders.

Download it from [Releases](https://github.com/Swofty-Developments/SwoftyLauncher/releases) or with the [installer](/guide/installation). The launcher offers each new release itself.

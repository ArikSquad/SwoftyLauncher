# 1.3.7

Swofty Launcher for F1 25 1.3.7 starts the game again with mods that rename menu nodes, names the addon behind every UI check message and puts your addons, their settings and their conflicts in Send Logs.

## Fixes

- A mod that renames a menu node without updating the hash stored beside its name no longer stops the launch. The 2026 Realism Patch's broadcast graphics does this with Photo Mode's logo nodes. The game finds those nodes by the stored hash, as before the rename, and the build lists them as warnings. A signal to a node that doesn't exist still stops the build. See [Checking UI edits](/reference/ui/patterns#checking-ui-edits).
- Every UI check message starts with the name of the addon that changed the resource.
- **Launch failed** shows the first line of the error, which says what failed, instead of its last detail.

## Send Logs to Developers

- `summary.txt` lists the active profile's addons by name: those on in load order, then the rest, each with its version, id, where it came from (built in, DB Editor, imported from which mod file, or installed) and the settings changed from their defaults. See [Send your logs to the developers](/using/send-logs).
- `addons.json` adds each addon's name, source, category, types, origin and settings.
- The zip includes `conflicts.json` from the active profile's last build: which addons change the same things, which one wins, and what they both change.

# 1.5.5

Swofty Launcher for F1 25 1.5.5 fixes the crash on Choose Driver in a new Driver Career, the crash on Braking Point's difficulty screen and a crash on Classic Seasons boxes. Large profiles install much faster, and Play checks the free space first.

## Fixes

- A new Driver Career no longer crashes on Choose Driver.
- Braking Point no longer crashes when a difficulty is picked.
- Pressing an addon season box no longer crashes after switching between Time Trial and Grand Prix.
- A mod's database removals skip the records community tracks add, and the build names the mod. The game crashed at startup when a mod removed them.
- The build repairs a track's AI pit lane that has no passing space, such as Autopolis'. AI cars crashed the game in that pit lane.

## Launching

- Play checks the free space on the game folder's and the data folder's drives before installing and says how much the profile needs. A drive that fills up during the install gets the same message.
- Large profiles install much faster, and the launcher keeps waiting while an install runs. It stopped after 10 minutes before.
- Mods load when Swofty Launcher was started with a Windows compatibility setting. The launcher no longer passes `__COMPAT_LAYER` to the game or the EA app.
- When F1 25 can't write in its own folder, the mod loader logs to `state/loader-fallback.log` in the Swofty data folder, and the launcher says why. It blamed antivirus before. Send Logs includes that log.
- A blocked offline play download says what usually blocks it: antivirus HTTPS scanning, a VPN or proxy, a network filter or a Wi-Fi login page. It no longer suggests a manual download.

## Addons

- Post-process passes run on every frame. Some frames, most of them in garages, skipped them before.
- [Career Mode Editor](/using/career-editor) 0.3.0 needs 1.5.5:
  - A driver who takes a seat in Driver Career signs that seat's contract. Before, the team showed one driver short. **Sign their seat contracts** on the Contracts card repairs careers an earlier swap left that way.
  - **Undo** works for seat swaps.
  - Race numbers can be changed, the player's included.
  - A planned weather intensity stays within the game's range.
  - The editor names a game version it doesn't support.

# 1.2.2

Swofty Launcher for F1 25 1.2.2 tells you when an antivirus has removed the launcher's files, and writes a crash report when the game crashes.

Before F1 25 starts, the launcher checks that the files it put in the game folder are still there, right away and again 2 seconds later. When an antivirus such as Windows Defender has deleted, quarantined or changed `version.dll` or the other launcher DLLs, F1 25 is not started: the game folder goes back to vanilla and a **Your antivirus removed mod files** dialog names the files and says how to restore them and add exclusions. When Windows refuses to copy a file as a threat, the launcher names that file and says how to restore it. Before, the game started without mods and nothing said why. See [If the mods don't load](/guide/windows#if-the-mods-don-t-load).

Once the game runs, the launcher checks that the mods loaded. When they haven't 45 seconds after the game starts, a **Mods did not load** dialog appears and says whether `version.dll` is gone from the game folder or was blocked.

When the game crashes, swofty_core writes `swofty/crash-<time>.txt` and a minidump beside it. That covers an exception that reaches the top-level filter, the game's own fatal heap errors and aborts, and a process exit with a non-zero code. The report holds the stack, the registers, the memory around them, the heap block at the faulting address, the loaded addons and modules, the recent screens, flow states and game-log warnings, the profiler counters and the last 200 `loader.log` lines. A fault while the report is written cuts only the section it hit. The core keeps the last 8 reports and 3 minidumps. After a session, `swofty run` prints a summary of the newest report.

**Send Logs to Developers** includes the newest crash report and its minidump, and `summary.txt` gains a summary of that report and a **Mod loader** section that says, for each session, whether the mods loaded. See [Send your logs to the developers](/using/send-logs).

| Variable | Effect |
|---|---|
| `SWOFTY_CRASH_DUMP=full` | The minidump holds all of the game's memory |
| `SWOFTY_CRASH_DUMP=off` | No minidump is written; the report still is |

Set them under `"env"` in `"launch"` in `$DATA/config.json`.

Download it from [Releases](https://github.com/Swofty-Developments/SwoftyLauncher/releases) or with the [installer](/guide/installation). The launcher offers each new release itself.

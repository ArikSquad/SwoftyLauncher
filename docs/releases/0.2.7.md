# 0.2.7

Swofty Launcher for F1 25 0.2.7 updates the offline play extension to 0.3.2. Modded sessions no longer hold the game at a delayed suspended startup — a short, clean start that protected builds expect.

Download it from [Releases](https://github.com/Swofty-Developments/SwoftyLauncher/releases). The launcher offers each new release itself.

## Offline play

- The session launcher starts the game promptly instead of keeping it suspended for seconds while looking for its image. The guard method arms at first sight as before.
- When the game's own loader never attaches, the run report now shows the session launcher's own log lines, so a run report says what method was used and what happened without digging through files.

# 1.6.1

Swofty Launcher for F1 25 1.6.1 keeps addons that set the same database id apart, names the track or season a crashing career needs, and lets the installer move your data folder.

## Launcher

- When an addon's `add-row` sets a `stat_id` that a row another addon added earlier in the build already holds, the new row gets the next free id, and references to it by label follow. The build warns with both addons and both ids, and the conflicts report counts it. Before, both rows kept the id and the game used the other addon's row: F1 2012 Season with Classic Seasons loaded Classic Seasons cars and engine sounds for the 2012 grid and crashed at session load on the audio heap.
- When F1 25 crashes setting up the track for a career's next session just after the career loads, and a track or season addon is off in the profile, the crash notice names it and says to turn it back on or change that round with the Career Mode Editor.
- The advice to turn off a track that runs out of game memory adds that a career whose next round is at that track needs the round changed with the Career Mode Editor first.

## Installer

- **Keep addons, profiles and backups in** chooses where the data folder lives. On an existing install, **Install** moves the data folder there and leaves a link at the old place, then updates the launcher. See [Moving the data folder](/guide/installation#moving-the-data-folder).

## Addon authors

- Leave `stat_id` out of `add-row`; the build gives each new row a free id. See [Stat ids](/reference/ops/database#stat-ids).

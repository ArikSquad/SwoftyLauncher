# 1.0.10

Swofty Launcher for F1 25 1.0.10 can start F1 25 in VR. The arrow next to **Play** offers **Play in VR**, which the launcher remembers for each profile, and `swofty run --vr` does the same from the command line. On Linux the launcher starts SteamVR first. See [Playing in VR](/using/vr).

The Career Mode Editor addon needs this release. It adds a **Career Editor** page that edits a running career in My Team and Driver Career: cash, resource points, renown, sponsor loyalty, cost cap refunds, driver ratings, seat swaps, contract money, R&D, facilities, the calendar, points and session weather. To install it, see [Career Mode Editor](/using/career-editor).

A damaged launcher state file no longer stops every launch; the launcher recovers it.

For addon authors:

- Database operation paths take a label selector on any segment, such as `track_data.game_setup.TrackDataSet[_metadata_=f1_2026].TrackData[_metadata_=okayama]`, in `select`, `field`, `value_from`, `add-row`, `put-record`, `remove-record` and track override paths. See [Selecting rows](/reference/ops/database#selecting-rows).
- Launcher plugin pages can use heroes, tiles, meters, cards, grids, forms, editable tables with search, tabs and live updates, and ask the host for the game's status and folders. See [Launcher API](/reference/addons/launcher-api).
- Core publishes the `flow.state`, `career.loaded`, `career.unloaded` and `career.hub` [events](/reference/std/events). Native plugins get [`swofty/career.hpp`](/reference/std/career) for the career entity, its components and the game's message bus, and [`swofty/mem.hpp`](/reference/std/memory) for checked memory reads. SDK API 6, `swofty.core` 0.2.11.
- `swofty::db::string_at` returns the decoded text of gamedb strings.

Download it from [Releases](https://github.com/Swofty-Developments/SwoftyLauncher/releases) or with the [installer](/guide/installation). The launcher offers each new release itself.

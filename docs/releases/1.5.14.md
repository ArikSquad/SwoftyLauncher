# 1.5.14

Swofty Launcher for F1 25 1.5.14 makes addons work on the EA app copy of F1 25, keeps an addon's careers in your save while the addon is off, and fixes the Discord **Log in** button on Windows.

## Launcher

- On Windows, a left click on **Log in** or **Log out** at the top right of the launcher signs you in or out. Before, it did nothing.
- The warning for a game installed where it can't write its own folder, such as an EA app copy in Program Files, no longer asks you to close the EA app and let Swofty start it. It says that the loader log and addon files go to the launcher's data folder for the session.

## In game

- On the EA app copy of F1 25, every game hook addons use resolves, as on Steam. Addon pages that use the game's view models, such as an addon's ADDON SETTINGS page, Progressive Career's settings page and its Team HQ tab, open instead of showing a blank page with Back not working.
- A view-model page whose view model can't attach is not opened, so Back keeps working.
- On a game installed where it can't write its own folder, such as an EA app copy in Program Files, the game keeps its scan caches in the launcher's data folder, so it no longer rescans the game on every start.
- When an addon whose careers the profile save holds is off, such as Progressive Career, the game keeps those careers in the save instead of dropping them, and they come back when the addon is on again.

## Addons

- **Progressive Career** 1.1.0:
  - On the EA app copy, Choose Driver shows the start season's suits, numbers and team badges, Team Select shows the season's cars and team logos, and the Resume Career card shows the career's year.
  - In a career that follows your driver's real career, the Team HQ contract event is gone; your driver's real team for next season is signed without it.
  - Race weekend and season titles show the career's year.
  - It is listed under **Career** in the Addon Browser.

## Addon developers

- When the game can't create files in `swofty/addons/<id>/`, as with an EA app copy in Program Files, an addon's storage for the session is in the launcher's data folder (`addon-storage/<id>/`), and reads fall back to the game folder for files that are only there. The storage API is unchanged. See [Storage](/reference/std/storage).
- When both the game folder and the data folder hold a storage file, the launcher keeps the one written last.

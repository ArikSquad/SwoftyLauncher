# Swofty Launcher 1.5

Swofty Launcher 1.5 brings addons to the EA app copy, a cleaner start for every player and a bigger Addon Browser. 1.5.5 is the current version and fixes the crashes reported through Send Logs.

## What's new

- **One-time setup.** The first **Play** after updating to 1.5 asks a few questions, then starts a clean record of your original game files. Verify the game in Steam or repair it in the EA app when it asks.
- **The EA app copy.** Addons that run code work there too: R&D: Tyres & Thermal Management, Career Mode Editor and **ADDON SETTINGS**.
- **Addon Browser.** Installing an addon also installs the addons it needs. Addons are sorted into Career, AI, Performance and Utility, downloads go up to 4 GB, and several addons can install at once.
- **ADDON SETTINGS** scrolls sideways when there are more tiles than fit.
- **Shader passes.** Addons can run their own post-process shaders on the race picture, under the HUD.
- **A faster launcher** with smooth scrolling, and an installer that finds and moves earlier installs.
- **Restart as administrator** when F1 25 is in a folder only administrators can change, such as the EA app's Program Files folder.

## Fixed in 1.5.5

- A new Driver Career no longer crashes on **Choose Driver**.
- Braking Point no longer crashes on the difficulty screen.
- Addon season boxes no longer crash after switching between Time Trial and Grand Prix.
- Community tracks no longer crash at startup when a mod removes database records, and Autopolis' AI no longer crashes in the pit lane.
- **Play** checks free space first, and large profiles install much faster.
- Career Mode Editor 0.3.0: seat swaps sign the seat's contract, **Undo** works for seat swaps, and race numbers can be changed.

# Swofty Launcher 1.3.0

Swofty Launcher 1.3.0 makes everything an addon. Mods, tracks and database changes now all use the Swofty addon format, so they install, switch on and off per profile, and stack in the same way.

## What's new

- **Mod Importer.** Drop a mod's zip, 7z, RAR or `.serps` on the launcher and the Mod Importer turns it into a Swofty addon. Mods you imported in an earlier version convert the first time 1.3.0 starts, in the same order and with the same switches.
- **DB Editor.** Change drivers, teams, line-ups, tracks, the calendar, weather, points and any other value in the game database, then save your changes as an addon to keep, stack and share.
- **Addons page.** Search, filter by category, type and source, drag addons into load order, and check which addon overrides which before you play.
- **News, Mod Importer and Tools** are in the sidebar. Tools lists other programs that make mods and addons for F1 25.

## Thank you, Team Simplified

The Mod Importer is built with Team Simplified, who made the Simplified Suite and the SERPs Launcher. Thank you for your help bringing it to Swofty. Team Simplified's tools will be among the first to make Swofty addons.

# Swofty Launcher 1.3.1

Swofty Launcher 1.3.1 plays any copy of F1 25 you have and makes updating one click.

## What's new

- **Steam and EA app copies.** Click the game name next to the cover art to pick the copy you play. **Play** starts Steam or the EA app to match, and **Play in VR** works with both.
- **One update.** When the launcher and the Mod Importer both have an update, one **Update** installs both and the launcher restarts once. A Mod Importer update never stops you from playing.
- **Mods made for earlier game versions.** A mod whose game database comes from an earlier update of F1 25 no longer removes the records later updates added, so the game starts instead of crashing.
- **Stop** closes only the copy you're playing.

# Addons, mods and tracks

You can load three kinds of content into F1 25 through the launcher. To install any of them, drop the file on the launcher window or use the Install or Import button on its page:

| | What it is | Install on |
|---|---|---|
| **Addon** | Pages, settings and engine code | [Addons](/using/addons) page |
| **Mod** | Content with no code | [Mods](/using/mods) page |
| **Track** | A community circuit (a kind of mod) | [Mods](/using/mods) page |

## Addon

An addon can change both your launcher and the game. Depending on what it carries, you get:

- **Settings** — toggles, sliders and choices you set per profile, in the launcher and in game.
- **Engine code** — new behaviour inside F1 25, such as a bigger grid or a HUD.
- **Pages** — an addon's own page in the launcher's sidebar. The built-in Team Simplified addon, for example, adds the **Mods** page.

Install your addon on the **Addons** page, then turn it on or off for each profile. You already have two addons with the launcher: **SwoftyMod**, which is always on in modded profiles, and **Custom Grid Size**, which lets you set how many cars race.

## Mod

A mod gives you content with no code: liveries, cars, in-game text and other packages. Import it on the **Mods** page, then choose its place in the list and turn it on for your profile. Order matters: if two mods change the same thing, the one lower in the list wins.

## Track

A community track, such as Sepang or Okayama, is a kind of mod, so you import its package on the **Mods** page too. Turn it on and you'll find it in Grand Prix track selection. There's no separate tracks page.

## Profiles and in-game settings

A [profile](/using/profiles) keeps your addons, mods, tracks and every addon setting together as one setup. To switch setups, switch profiles. You can choose the built-in `vanilla` profile for a setup with nothing installed.

To change settings while you play, open **ADDON SETTINGS** in the home menu, directly under **Career**. You'll find every enabled addon and track there; open one to change its settings without leaving the game. See [In-game addon settings](/using/swofty-mod).

To build your own, see [Creating mods](/reference/mods/) and [Creating addons](/reference/addons/).

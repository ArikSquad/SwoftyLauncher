# Making an addon

An addon adds code, settings and in-game screens to F1 25. Making one is covered in the Reference, under [Creating addons](/reference/addons/). The [Standard library](/reference/std/) lists every API an addon can use, and the [Game API](/reference/game/) lists the game functions a plugin can call and hook.

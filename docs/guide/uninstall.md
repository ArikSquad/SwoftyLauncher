# Uninstalling

1. Close F1 25.
2. Run `swofty restore`. If it reports files it could not restore, resolve those first.
3. On Linux, clear F1 25's launch option in Steam.
4. Remove the launcher and its [data folder](/guide/installation#where-your-files-are-stored).

Deleting the data folder removes your installed addons, mods, profiles, backups and any saves stored there. Keep a copy of anything you want to use later.

Steam's **Verify integrity of game files** can repair game files, but it does not remove files added by the launcher. See [Restoring the game](/using/profiles-and-restoring).

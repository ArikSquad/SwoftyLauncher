# T002 Does swofty_trace.dll install and log in the real game without disturbing it?

- Requested by: re-infra, 2026-10-17
- Status: queued
- Session: SESSION-1 together with T001 (`re/tests/SESSION-1.runtime.trace.json` holds both tests' hooks)

## Question
Does `swofty_trace.dll` load after the core mod, install its two func_start hooks, and write correct trace lines in the real game without crashing or changing behaviour?

## Hypothesis
The plugin has only run against a fake exe under plain Wine (`re/trace_plugin/test/`). In the real game it should log `H ... result=match` (sha256 check about 1 s), install both hooks, and log one `E` line per home command and per item populate. `cmd` should decode as the NeStr of the command name, and its hash should equal the djb2 values in `strings_anchors.tsv` (`h_select_pressed` 0x02b0357a, `h_focus_changed`, `h_back_pressed`, ...).

## Promotes
On pass: the trace plugin is cleared for use in later tests (it is a tool, not a KB item). KB: `h_select_pressed`, `h_focus_changed`, `h_back_pressed` to L3 (hash seen with the matching chars); `FEHomeViewModel.tile_list` and `FEHomeViewModel.focused_id_hash` to L3 if the values are plausible (non-null pointer; hash equal to a focused item's id hash); `FeTile_ItemBase_Populate` callers (`bt`) recorded.

## User steps
1. Same install as T001 (one session).
2. At the home menu, move focus down three tiles and back up, open Options, press Back.
3. Play for at least 10 minutes in total (T001's race counts), then exit normally.

## Expected log lines
- `^H .* result=match` → build check passed in the real process.
- `^H .* status=active hooks=4 installed=4 rejected=0` → all session hooks installed.
- `^E .* hook=t002\.on_command .* cmd=0x70d928ee:"focus_changed"` → command NeStr decoded; hash matches `h_focus_changed`.
- `^E .* hook=t002\.on_command .* cmd=0x02b0357a:"select_pressed"` → select path.
- `^E .* hook=t002\.item_populate .* item_id=0x[0-9a-f]+:"career"` → populate sees the Career item id.
- `^H .* end=1` → clean shutdown with final summary.
Pass: all of the above and no crash. Fail: any crash with the plugin present that does not reproduce without it.

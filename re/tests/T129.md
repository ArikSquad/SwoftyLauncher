## Question
Does the game boot to the main menu when the value map is reserved at 2^22 buckets (a 71,307,511-byte block from the GAME_VALUE_DB heap)?

## Hypothesis
`Gdb_HashMap_Rehash` allocates (n + 255) * 17 + 8 bytes through `Gdb_RecordAlloc_AllocBlock` -> the GAME_VALUE_DB heap (`GdbDatabase.heap`); a null result is fatal (0x1403139f0). 2^21 (35,655,927 B) is proven by the 1.5.11 file-route boot. Whether the heap has a fixed budget that refuses 2^22 is not known statically (the heap is looked up by name through the memory manager). If 2^22 boots, the core's cap is 3,355,443 records; if not, the cap is 1,677,721.

## Promotes

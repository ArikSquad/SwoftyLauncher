## Question
Do two careers of one mode with the same driver carry different slot_guid values, and does each keep its slot_guid through a save and reload?

## Hypothesis
`subsystems/game.md#save-heaps`, `structs/SaveSlotInfo.h`. `slot_guid` (+0x8) and `slot_id` (+0x0) are copied verbatim at load and written back at save, so each is stable; `slot_guid` is presumably made unique when the slot is created (that code is not found yet). `site_Game_SaveSlot_Selected` sees the slot in rbx when a career loads.

## Promotes
- `SaveSlotInfo.slot_id`, `SaveSlotInfo.slot_guid`, `SaveSlotManager.current`, `Game_SaveSlotManager_SelectSlot`, `site_Game_SaveSlot_Selected`: L2 -> L3.
- Equal `slot_guid` values on two careers, or a value that changes across a reload, rules `slot_guid` out as the career key (fall back to mode + `slot_id`).

Pass rule: the two careers show different `slot_guid` values, and each career shows the same `slot_guid` in steps 1 and 2. Fail rule: equal values or a changed value.
